בדיקת דפדפן ראשונית חשפה אתחול HTML לפני שקיים DOM, קריאת Scale מוקדמת וגישה ל־Physics World אחרי ש־Phaser השמיד אותו ב־shutdown. שלושת הליקויים תוקנו ונבדקו שוב. Chromium המותקן בסביבה דרש Unix socket חסום, ולכן בדיקות המשחק נעשו ב־Chrome Headless Shell. Vite מציג אזהרת גודל לקובץ היחיד הכולל את Phaser.

## שחזור הבדיקות

מתוך `plasma-arena/`, התקינו מראש Python Playwright ו־Chromium או Chrome Headless Shell. הגדירו את `CHROMIUM` לנתיב הבינארי שבחרתם.

```sh
npm ci
npm run check
python tests/browser_qa.py
python tests/gameplay_qa.py
python tests/touch_qa.py
python tests/json_extension.py
python tests/webgl_smoke.py
```

הרצת לחימה רגילה מושפעת ממסלול הפלזמות האקראי ומקצב הדפדפן. המטרה בבדיקתה היא תיעוד פגיעות אמיתיות והתפצלות, והסיבוב יכול להסתיים בזמן הקצוב. בדיקת הניצחון המבוקרת מוודאת את מנגנון המעבר בין הגלים. טלמטריה מסמנת בנפרד נזק שהופעל על ידי probe.

## נקודות לסיבוב הבא

- הוזזה נקודת הופעה אחת בסיפון הממסר מ־x=480 ל־x=585. כך מוקש שנולד שם יוצא הצידה מעבר למשטח המרכזי במהלך הסיור.
- תזמון גל והרכבתו עדיין בתוך `GameScene`. המודולים הקיימים לפלזמה, נשק, תנועה וסכנות מטפלים בהתנהגות; חילוץ מתזמן נוסף מתאים כשהזירות יצטרכו תנאי גל חדשים.
- תוכן מותאם שחוסם את כל נקודות ההופעה הבטוחות עלול להשאיר הופעות בהמתנה. גם תצורת משטחים חדשה דורשת פלייטסט לעבירות ולזוויות הירי.
