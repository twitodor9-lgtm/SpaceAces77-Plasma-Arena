# Plasma Arena — מסירה ובדיקות בעל הפרויקט

הסוכן מבצע בדיקות טכניות ומוסר תוצר שניתן לבדיקה. **הערכת הכיף, הקושי, הזרימה והאיזון שייכת לבעל הפרויקט.**

## מה צריך להוכיח טכנית לפני המסירה
- אפשר להתקין/לבנות את הפרויקט מה־ZIP.
- המשחק נפתח עם Start, שחקן, גלים, Win/Lose/Retry.
- כל נתוני המשחק נטענים מקבצי הקונפיגורציה והסכמות מזהות טעויות.
- סקריפטים/בדיקות אוטומטיות בודקים שרשראות התפצלות, גבולות גופים, Win conditions, Restart והרחבה נתונית.
- אין משיכה של CDN או נכס בזמן הפעלה אופליין.
- דיווח על בדיקת דפדפן רק אם אכן בוצעה; אחרת לסמן Not Tested.

## מה נבדוק בעצמנו
- האם הגושים מספקים קצב ארקיידי כיפי?
- האם ההתפצלות ברורה ולא הופכת לצפופה מדי?
- האם הנשקים מרגישים שונים ומשמעותיים?
- האם פגיעה מרגישה הוגנת? האם הנקודות הבטוחות צפויות?
- האם כל זירה מכילה עניין בלי להסתמך על גרפיקה מפוארת?
- האם החלפת JSON מוסיפה אויב/נשק/גל בלי עריכת TypeScript?
- האם השלב מובחן מ־Flight, Ground ו־Plasma Sea?
