# SpaceAces77 — Plasma Arena / Grok Starter v0.1

**משימה עצמאית עבור Grok.** זירת פלזמה בסגנון ארקייד, **לא** Plasma Sea שבאחריות Claude.

## סדר קריאה
1. `GDD_PLASMA_ARENA_v0.1_HE.md` — החוויה והגבולות.
2. `PROMPT_GROK_PLASMA_ARENA_HE.md` — הוראות הפיתוח המחייבות.
3. `MODULAR_CONTENT_CONTRACT.md` — החוזה להרחבת תוכן ללא שינוי ליבה.
4. `ACCEPTANCE_FOR_OWNER_QA.md` — מה יש למסור כדי שבעל הפרויקט יוכל לבצע בדיקות משחק.
5. `CAMPAIGN_STAGE_MAP_v0.2_HE.md` — מיקום מוצע בקמפיין; אינו קאנון מאושר.
6. `examples/*.json` — דוגמאות סכמטיות בלבד, לא קוד משחק קיים.

## גבולות וסמכויות
- אין בקבצים הללו קוד מקור קיים של Phaser. אם יסופק בסיס Phaser מתאים, בדוק וקרא אותו לפני שינוי.
- פתח אב־טיפוס עצמאי; אין לדרוס או לשנות את Plasma Sea, Flight, Ground, Death Moon Run או Aces Titan.
- ללא Merge וללא שינוי `main` או `integration/lab`.
- בדיקות המשחקיות והאיזון יבוצעו על ידי בעל הפרויקט. הסוכן מחויב לבדיקות טכניות אמיתיות ולדיווח על מגבלות.
