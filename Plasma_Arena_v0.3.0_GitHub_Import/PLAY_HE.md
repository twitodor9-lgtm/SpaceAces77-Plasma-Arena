# Plasma Arena — איך משחקים

פתחו את `Plasma_Arena.html`, בחרו **תא הליבה** או **סיפון הממסר** ולחצו **התחל**. פנו שלושה גלים כדי לנצח. גושים גדולים מתפצלים, וסמל אזהרה מסמן היכן יופיעו גושים חדשים או מתי סכנה עומדת להידלק.

| פעולה | מקלדת |
|---|---|
| תנועה | A/D או חצים ימינה ושמאלה |
| קפיצה | W, חץ למעלה או רווח |
| ירי רציף | לחיצה ממושכת על J או K |
| בחירה ישירה | 1 לחנית אנרגיה, 2 לרשת דופק |
| מעבר בין נשקים | Q/E |

במסך מגע השתמשו בכפתורים שבתחתית. נקודות הכוונת מראות את כיוון הירי. הירייה עולה אנכית בעמידה ונוטה לכיוון התנועה. חנית האנרגיה פוגעת, ורשת הדופק יוצרת שדה האטה זמני. מצב האנרגיה ניתן לבחירה בתפריט. חנית האנרגיה זמינה גם כשהמאגר ריק.

לחצו **שוב** כדי לפתוח סיבוב חדש באותה זירה, או **תפריט** כדי להחליף זירה ומצב אנרגיה. השיא נשמר מקומית כשהדפדפן מאפשר שמירה ל־HTML מקומי.

## כלי בדיקה

הוסיפו `?qa&boxes` לכתובת ה־HTML (למשל `file:///…/Plasma_Arena.html?qa&boxes`). `boxes` מציג את גופי ההתנגשות של השחקן והפלזמות. במהלך סיבוב או במסך תוצאה השתמשו ב־DevTools Console ליצוא הטלמטריה:

```js
copy(window.__controlsTest.exportTelemetry())
```

הדביקו את הפלט לקובץ JSON. חזרה לתפריט או Retry סוגרים את הגישה לנתוני הסיבוב הקודם.
