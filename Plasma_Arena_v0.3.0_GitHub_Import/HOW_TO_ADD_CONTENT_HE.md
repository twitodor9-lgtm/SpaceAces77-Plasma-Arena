# הרחבת Plasma Arena באמצעות JSON

כל הדוגמאות מתחילות בתיקיית `plasma-arena/data/`. השתמשו במזהים חדשים ויציבים ובמקשי התנהגות קיימים.

| מה מוסיפים | היכן ואיך |
|---|---|
| פלזמה | העתיקו רשומה ב־`entities.json`, שנו `id`, `radius`, `hp` והתנהגויות. ל־split הגדירו `childId` קיים ו־`count`. |
| נשק | העתיקו רשומה ב־`weapons.json`, הוסיפו את ה־ID לסוף `balance.weaponsOrder`. הנשק הראשון צריך לגרום נזק ללא עלות אנרגיה. |
| גל | הוסיפו רשומה ל־`waves` בזירה. `spawns` כוללים מזהה פלזמה וכמות. `events` מוסיפים הופעות בהשהיה. |
| סכנה | הוסיפו סוג ב־`hazards.json` ומופע עם `ref` בזירה. `horizontal_patrol` דורש `x2`. |
| זירה | העתיקו קובץ תחת `arenas/`, החליפו `id`, התאימו נקודות, משטחים וגלים. רוחב וגובה תואמים ל־`balance.arenaSize`. |
| נכס | הוסיפו צבעים ומוטיב נתמך ב־`assets.json` והפנו ל־ID המתאים. הנכסים נוצרים מקומית. |

הריצו `npm run check`, פתחו את `dist/Plasma_Arena.html` ובחרו את הזירה החדשה. הבנייה טוענת אוטומטית את כל קובצי `data/arenas/*.json`. ולידציה מלאה מתרחשת גם בעת הפעלת המשחק. בדקו את ה־HTML כדי לראות אם תוכן שגוי מציג הודעת טעינה. השתמשו ב־`python tests/json_extension.py` להדגמה אוטומטית של כל חמש ההרחבות על עותק מבודד.

בחרו נקודות הופעה רחוקות זו מזו וממשטחים. הופעה מתוכננת תחכה למיקום בטוח ולמקום תחת תקרת הגופים. שמרו גם את רדיוס הבטיחות והפריסה בתרחיש שמאפשר בפועל להופיע מכל אזור שאליו יכול להגיע השחקן. התנהגות חדשה מעבר למפתחות הנתמכים דורשת מימוש במודול המתאים ועדכון הוולידציה.
